# TeamScope Paraguay 🔭🇵🇾

Plataforma de Clima Laboral con IA para equipos de TI — adaptada a Paraguay.

## Funcionalidades

- ✅ Dashboard en tiempo real con Firebase
- ✅ Encuesta anónima por equipo (Desarrollo, QA, DevOps, Data, Soporte)
- ✅ Score de clima calculado automáticamente
- ✅ Alertas automáticas por equipo en riesgo
- ✅ Comentarios abiertos anónimos
- ✅ Cumple con Ley 1682/01 de Datos Personales — Paraguay

## Despliegue

Este proyecto está listo para desplegar en Vercel. Solo conectá el repositorio a Vercel y se despliega automáticamente.
